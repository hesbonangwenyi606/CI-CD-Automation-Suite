# CI-CD Automation Suite
A modern DevOps platform designed to streamline Continuous Integration and Continuous Deployment (CI/CD) workflows through automation, monitoring, security checks, and deployment management.

## Overview
CI-CD Automation Suite helps development teams automate software delivery pipelines, reduce deployment risks, improve code quality, and accelerate release cycles.
The platform provides an intuitive dashboard for managing build pipelines, monitoring deployments, integrating development tools, and enforcing security best practices throughout the software development lifecycle.

## Installation

Clone the repository:

```bash
git clone https://github.com/hesbonangwenyi606/CI-CD-Automation-Suite.git
```

Navigate into the project:

```bash
cd CI-CD-Automation-Suite
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
